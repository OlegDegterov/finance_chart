# Finance Chart

График доходов и расходов: прогноз по месяцам на общих осях. Статьи задаются как регулярные
или разовые потоки (зарплата, аренда, жильё, еда, образование) либо как депозит (сумма, ставка,
капитализация). Данные хранятся только на устройстве, бэкенда нет.

Работает как PWA (iPad, iPhone, десктоп через браузер) и как нативное приложение через Capacitor.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # юнит-тесты движка расчёта (Vitest)
npm run e2e          # Playwright, WebKit: iPad Pro 11, iPhone 14, тёмная тема
npm run build        # production-сборка в dist/ вместе с service worker
npm run preview      # проверка PWA-сборки, http://localhost:4173
```

Перед первым `npm run e2e` нужно скачать браузер: `npx playwright install webkit`.

## Структура

```
src/domain/      модель, расчёт прогноза (projection.ts), агрегация по кварталам/годам, валидация файла
src/storage/     адаптеры хранилища: IndexedDB (веб) и Capacitor Preferences (нативная сборка), экспорт/импорт
src/store/       Zustand-стор с persist, демо-сценарий
src/features/    items — список и форма статей, chart — график (ECharts) и таблица, settings — стартовый остаток, экспорт
src/app/         раскладка (split-view на iPad, вкладки на телефоне), тема
e2e/             Playwright-тесты
```

## Режимы графика

- **Линии** — по статьям, по категориям или итоги; доходы сплошные, расходы пунктиром.
- **Доходы и расходы** — две суммарные линии и заливка между ними (профицит/дефицит).
- **Баланс** — накопительный остаток от стартового капитала.
- **Слоями** — stacked area: доходы вверх, расходы вниз.

Валюта сценария выбирается в настройках (RUB, USD, EUR, BYN, JPY, GBP, CNY, AUD, CAD); это только обозначение, суммы при смене не пересчитываются.

Масштаб: pinch и колесо мыши, слайдер снизу, шаг месяц/квартал/год, горизонт 1–10 лет от текущего месяца.

## Установка на iPad как PWA

Открыть адрес приложения в Safari → «Поделиться» → «На экран Домой». Приложение работает офлайн.
Данные хранятся в браузере — делайте экспорт в JSON (Настройки) для резервной копии.

## Нативные сборки (Capacitor)

```bash
npm run cap:ios      # сборка, sync и открытие проекта в Xcode
npm run cap:android  # то же для Android Studio
```

Для iOS нужен полный Xcode (не только Command Line Tools); для Android — Android Studio с SDK.
Установка на реальный iPad: бесплатный Apple ID даёт профиль на 7 дней, платный аккаунт разработчика — на год.
